# Accurate — updates

The Sparkle update feed and notarised builds for [Accurate](https://github.com/common-era-uk/accurate),
Common Era's shoot-estimating app.

This repo is public only because Sparkle sends no credentials and so can't read a private
feed. It holds the appcast and the built app; the source lives in the private repo above.

Builds are attached to each [release](https://github.com/common-era-uk/accurate-releases/releases).
